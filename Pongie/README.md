# 🏓 Pongie (乒嗒) - 乒乓球手绘风情感打卡 iOS App

一款专门为乒乓球爱好者打造的 iOS 原生手绘风打卡与装备记录 App。打破传统冷冰冰的数据表格，将每一次击球、比赛与训练化作具有**错乱之美**的动态手绘乒乓球。

## 🌟 核心特色 (Core Features)

1. **手绘涂鸦与错乱之美 (Doodle Art & Chaotic Beauty)**：
   - 温暖可爱的蜡笔/手绘笔触风格。
   - 掉落的乒乓球尺寸动态变化（🏆大号大胜球、🏸中号常规球、💦小号短练球），在碰撞球池中形成自然高低错落的倾斜美感。
2. **物理情绪球池 (SpriteKit Physics Pool)**：
   - 真实的球体碰撞、重力沉降与点击弹跳动画。
3. **装备日志 (Gear Log)**：
   - 记录底板 (Blade)、正手胶皮 (Forehand Rubber) 和反手胶皮 (Backhand Rubber) 累计使用时长与磨损度提示。
4. **数据统计与小组件 (Analytics & WidgetKit)**：
   - 胜率统计、打法特征分析、月度打卡热力网格与 iOS 桌面小组件。

## 💻 技术栈 (Tech Stack)

- **Swift 6 & SwiftUI** (iOS 17+)
- **SwiftData** (轻量化本地持久化)
- **SpriteKit** (物理碰撞球池)
- **WidgetKit** (iOS 桌面小组件)

## 🚀 Xcode 运行指南 (How to Run in Xcode)

1. 打开 Xcode 15+ 或 16。
2. 新建 SwiftUI Project：
   - Product Name: `Pongie`
   - Interface: `SwiftUI`
   - Language: `Swift`
   - Storage: `SwiftData`
3. 将 `Pongie/` 目录下的所有源文件拖入 Xcode 工程中即可直接运行并体验！
